# 清简使用指南

**清简可以帮助你在网页里混合输入中文和英文（即输入法会自动识别你输入的是中文还是英文），也可以把已经打好的拼音转换成汉字。它不会替换微软输入法。**

**如果你只想在网页里使用，只安装 Edge 插件就够了。需要在 Word 等桌面软件中转换拼音时，再使用桌面助手。**

## 1. 了解两个部分

### 1.1. Edge 插件：在网页里使用

![清简 Edge 插件图标](guide-images/edge-extension.png)

这是 Edge 工具栏里的清简图标，点击它可开启中英混合输入、设置网站权限。初次安装后时，可通过点击浏览器右上角的拼图图标，找到清简并固定到工具栏。

打开 Edge 后，插件会随浏览器一起加载。它可以在中英混合输入中显示拼音的**5组候选词**，也能将网页里选中的拼音转换成汉字。普通词库功能不需要先打开桌面助手。

### 1.2. 桌面助手：在其他软件里使用

![清简桌面快捷方式图标](guide-images/desktop-shortcut.png)

这是桌面上名为“清简”的快捷方式图标。双击它启动桌面助手；需要暂停或退出时，在屏幕右下角的托盘(⌃图标）中找到同一图标。

桌面助手是一个解压后运行的 Windows 程序，主文件叫“清简.exe”。它不是商店应用，也没有登记到 Windows 的“已安装的应用”列表里。

桌面上的“清简”图标是快捷方式，相当于指向程序文件的入口，并不是又复制了一份程序。因此，安装后请保留整个 `Qingjian-V2` 文件夹，不要只留下 exe，也不要随意移动或改名。

### 1.3. 适用的电脑

网页功能需要现代桌面版 Edge，最低版本为 119，建议使用电脑支持的较新版本。桌面助手面向 Windows 10／11 的 64 位电脑，需要 .NET Framework 4.8；若系统提示缺少它，请从微软官方渠道安装。

不同电脑、网站和输入框会有差异。32 位或 ARM 电脑上的桌面助手尚未充分验证。单位管理的电脑如果不允许安装扩展，请联系管理员，不要绕过限制。

### 1.4. 目前测试兼容的范围

以下根据本机测试和试用反馈整理，兼容范围包括但不限于下列场景；不是对所有软件版本、所有页面和所有输入框的保证。

| 环境 | 目前兼容的常见场景 | 使用方式 |
| --- | --- | --- |
| Edge 主流网页、AI 对话网页 | ChatGPT、Gemini、DeepSeek、豆包等网站的常见可编辑文字输入框；其他普通网页输入框也可试用 | 网页混输用空格选词；已有拼音选中后按 Ctrl+Shift+Z |
| Windows 桌面程序 | Codex、Claude、记事本、Microsoft Word 等软件的常见文字编辑区域 | 先启动桌面清简，选中已有拼音，按 Ctrl+Shift+Z |
| 尚不兼容可靠原位替换 | 微信、Microsoft Excel、PowerPoint（PPT） | 请使用“备用转换窗口”，自行复制、转换、粘贴 |

桌面助手只负责转换选中的已有拼音，不在这些桌面软件里提供自动中英混输。中英混输和候选栏属于 Edge 插件功能。Word 仅限可编辑正文等受支持区域，受保护、只读、密码或特殊控件可能不支持直接替换。

## 2. 第一次安装

### 2.1. 安装 Edge 插件

1. 下载 `Qingjian-Edge-v0.5.4.3.zip`，右键选择“全部解压缩”，放到一个以后不会随手删除的位置。
2. 打开 Edge，在最上方显示网址的位置输入 `edge://extensions`，按回车。
3. 开启页面上的“开发人员模式”。这是 Edge 里的开关，不需要修改 Windows 的开发者设置。
4. 点击“加载解压缩的扩展”，选择解压后名为 `Edge` 的文件夹。选对后，里面应该能看到 `manifest.json`。
5. 扩展列表出现“清简”后，点击浏览器右上方的拼图图标，找到清简。可以把它固定在工具栏，之后更容易打开设置。

加载完成后，不要删除或移动这个 `Edge` 文件夹。网站是否启用，请按第 3 节设置。

### 2.2. 安装桌面助手（按需）

1. 下载 `Qingjian-Windows-x64-v0.5.4.3.zip`，完整解压，保留里面的 `Qingjian-V2` 文件夹和全部文件。
2. 在文件资源管理器里打开这个文件夹，双击一次 `Install.cmd`。
3. 首次启动会创建桌面“清简”快捷方式，并询问是否开机启动。不想自启，选择“否”即可。
4. 以后直接双击桌面“清简”，不必每次再运行 `Install.cmd`。

如果点开脚本后只看到代码文字，说明打开的是预览。请回到文件资源管理器中双击它。

## 3. 选择在哪些网站使用

下面的设置都从浏览器工具栏的“清简”图标进入。初次使用，建议先只开启自己常用的网站。

### 3.1. 只在一个或几个网站使用

1. 打开想使用清简的网站。
2. 点击“清简”图标，保持“所有网站自动启用”不勾选。
3. 点击“在此网站启用”，在 Edge 的提示中允许访问这个网站。
4. 回到输入框试用；如果页面提示需要刷新，刷新一次即可。

想再加一个网站，就在那个网站重复以上步骤。以前开过全站访问的，可以先关闭全站选项，再分别授权需要的网站。

### 3.2. 在所有普通网站使用

1. 打开一个普通网页，点击“清简”图标。
2. 勾选“所有网站自动启用（需授权）”。
3. 阅读 Edge 的授权提示，确认愿意授予较广的网站访问权限后再允许。

以后打开新网站，一般不用再单独开启。浏览器设置页、某些特殊输入框和网站限制仍可能导致无法使用。

### 3.3. 全站开启，但排除某个网站

1. 保持全站选项开启，打开要排除的网站。
2. 点击“清简”图标，选择“在此网站禁用”并刷新网站。
3. 看到已禁用的提示后，这个网站会停止使用清简，其他网站不受影响。
4. 想恢复时，回到这个网站，点击清简弹窗里的“恢复此网站”并刷新网站。

网站跳转到另一个地址后，建议再检查一次。例如 `example.com` 和 `login.example.com`、`http` 和 `https` 地址可能需要分别设置。

### 3.4. 登录账号时，怎样更放心？

输入用户名、密码、验证码、银行卡号前，建议先停用清简。最直接的方法是打开 `edge://extensions`，把清简卡片上的总开关关闭；登录完成后再打开，不用卸载。

“在此网站禁用”适合日常排除，但不会撤销 Edge 以前授予的网站访问权限。需要更严格地限制访问时，请在 Edge 扩展详情里调整网站权限，或关闭整个扩展。只关闭“自动混输”，不等于整个插件都已关闭。

Edge 自带的“网站访问权限”子菜单不能由清简添加选项；请使用清简自己的弹窗。程序会尝试避开密码框，但网站可能使用特殊控件，因此不要拿真实密码或其他机密信息试转换。

## 4. 在网页里打字

### 4.1. 最基本的操作

1. 先把微软拼音切到英文输入状态，让清简能够看到你输入的字母。
2. 输入 `nihao`，出现“你好”等候选后，按空格选择默认结果。
3. 想选其他候选时，按对应的数字 1—5，或直接点击候选。
4. 想保留英文或拼音时，按 Esc；选错了可以按 Ctrl+Z 撤销。

空格是选词键，不需要按回车来确认。很多聊天网站会把回车当作发送消息。

### 4.2. 一些方便的省略输入

| 输入 | 常用结果 |
| --- | --- |
| `zhem` | 这么 |
| `nam` | 那么 |
| `zenm` | 怎么 |
| `shenm` | 什么 |
| `weishenm` | 为什么 |
| `ne`、`de`、`shi` | 呢、的、是等候选 |

这些短词需要按空格或数字确认，不会字母刚出现就直接改字。“he”“me”“you”等容易与英文重叠的输入，会优先保留英文。

### 4.3. 怎样打得更顺手？

**1. “呢、的、是”等词最好和前后内容一起打。 虽然常用单音节已有候选，放进完整词句里通常更容易选对。**

**2. 中英文交界处善用空格。 先把中文候选确认上屏，再输入英文；英文结束后再用空格分开。**

**3. 生僻、新颖的表达或专有名词，可以切回微软拼音中文模式。 不用勉强让清简识别。**

**4. 大段中文建议使用原生中文输入法。 清简更适合网页短句、中英混输，以及已有拼音的转换。**

**5. 如果有些时候发现想要的词语没有出现，不妨多打一些字符，更有利于识别出中文。**

## 5. 转换已经输入的拼音

### 5.1. 网页里的拼音

在已启用清简的网页里，选中一段拼音，按 **Ctrl+Shift+Z**。输入框支持编辑时，清简会尝试原位替换；只读内容可能只显示转换结果，供你复制。

### 5.2. Word、桌面 Codex 等软件

1. 双击桌面“清简”，等待词库就绪。
2. 在软件中选中已有拼音，按 **Ctrl+Shift+Z**。
3. 转换期间先不要继续打字、改变选区或切换窗口，避免操作被取消。

Word 优先通过 Word 自身的选区接口替换；桌面 Codex 等编辑器需要能向系统提供可验证的文本选区。桌面功能不需要打开 Edge。转换前后若选区或光标发生变化，清简会取消操作，保留原文。

本版结合了标准 Windows 编辑框检查、后台恢复检查和真实使用反馈。Word、Codex、Claude、记事本的常见编辑区域属于当前兼容范围，具体版本及特殊控件仍以实际表现为准；不支持的输入框请使用备用窗口。

### 5.3. 微信、Excel、PPT 或其他不能直接替换的输入框

微信、Excel、PPT 目前不支持可靠的快捷键原位替换，可以使用备用窗口：

1. 选中拼音，按 Ctrl+C 复制。
2. 在屏幕右下角找到清简托盘图标，右键选择“备用转换窗口”。图标可能藏在向上的小箭头里。
3. 粘贴到“拼音”区域，点击“转换”，或按 Ctrl+Enter。
4. 看一下结果，点击“复制结果”。
5. 回到原软件，确认光标位置，再按 Ctrl+V 粘贴。

备用窗口不会替你读取其他聊天框，也不会自行决定粘贴位置。

## 6. 平时怎样启动和关闭？

### 6.1. 不用纠结谁先开

| 你要做什么 | 需要打开什么 |
| --- | --- |
| 网页词库混输、网页拼音转换 | 打开 Edge 即可，插件随浏览器加载 |
| Word 等桌面软件的拼音转换 | 双击桌面“清简” |
| 网页本地 AI 辅助 | Edge 插件和桌面清简都运行，并准备好模型；先后顺序不限 |

清简先准备词库，不等待大型 AI 模型加载；AI 没就绪时直接使用词库结果。启动耗时会受电脑性能和安全扫描影响，请以托盘“词库就绪”为准。

程序在后台运行时，不一定弹出主窗口。可以双击托盘图标查看“状态与用法”。第一次从新目录启动可能要多等几秒，以词库就绪提示为准。

### 6.2. 暂停或退出

右键清简托盘图标，可选择“暂停快捷键”或“退出”，也可更改是否开机启动。关闭 Edge 不会自动退出桌面助手；关闭一个网页标签，也不等于关闭插件。

## 7. 学习功能和本地 AI

### 7.1. 让常用词更符合自己的习惯

在清简弹窗里打开“学习选词习惯”后，尽量用数字或鼠标明确选择正确候选，这比直接按空格更容易形成偏好。经常确认同一个表达，它会逐渐更靠前；撤销错误结果则会降低对应偏好。

它不会一次就学懂所有表达，也不会训练一个新的大模型。日常选词记忆使用轻量的本地排序，本地 AI 只在需要时辅助判断候选。

不想继续学习，可以关闭该选项。已有记录不会自动删除；想删除时点击“清除学习记录”。如果提示只清除了网页记录，先启动桌面助手，再清除一次。

### 7.2. AI 放在哪里？是否必须下载？

**AI 是可选的，不下载也能使用词库。需要时，在助手文件夹里运行 `Download-AI.cmd`，按提示确认下载约 2.5GB 的模型；下载时需要联网，模型会进行完整性校验。**

模型存放在助手目录的 `models` 文件夹，文件名为 `qwen3-4b-instruct-q4_k_m.gguf`。运行它的引擎位于 `runtime\llama` 文件夹。安装后不要单独移动这些文件。

模型推理在本机进行，不需要外接云 AI 账号或付费 API。电脑内存紧张、AI 较慢或没有必要时，继续使用词库即可。AI 和词库都可能选错同音词，仍建议看一眼结果。

## 8. 隐私、安全和常见问题

### 8.1. 会保存什么？

清简不会持续记录你的完整打字过程，也不把输入发送给云 AI。开启学习后，会在本机保存确认过的短词、拼音、使用次数，以及用于区分前后文的摘要。短词也可能涉及隐私，摘要并不等于加密；敏感场景建议关闭学习，并按需清除记录。

不要把自己正在使用的整个程序目录或浏览器资料发给别人，其中可能含连接配置和学习记录。需要分享时，使用项目提供的干净下载包。

### 8.2. 下载和开发者模式要注意什么？

GitHub 下载包通过 Edge 开发者模式加载，不等于经过扩展商店审核。只从可信发布页获取，不加载陌生人发来的脚本目录或更新包。

如果发布页提供 `SHA256SUMS.txt`，里面的数字是文件“指纹”，可用来核对下载文件有没有变化。程序尚未进行商业代码签名，Windows 可能提示未知发布者；请先核实来源，不要为了运行而关闭杀毒软件或绕过单位策略。

### 8.3. 没有反应怎么办？

1. 网页中，先看清简是否开启、当前网站是否授权或被禁用，再刷新页面试一次。
2. 桌面中，先看托盘是否存在、词库是否就绪、快捷键是否暂停。
3. 特殊网页编辑器、管理员窗口、终端和受保护输入框可能不支持，可以切回原生输入法或使用备用窗口。

同音词、缩写和新表达会误识别，网站更新后也可能暂时失效。不要用清简自动处理需要绝对准确的机密或重要内容。

### 8.4. 快捷键和剪贴板

Ctrl+Shift+Z 可能与“重做”等操作冲突。浏览器里可在 `edge://extensions/shortcuts` 查看分配，或关闭扩展；桌面里可暂停清简快捷键。即使只禁用了一个网站，Edge 仍可能预留这个键位。

Word 优先通过自身正文接口转换，普通编辑框可直接替换；Codex、Claude 等程序的兼容路径可能临时使用剪贴板。清简先尝试备份，再核对选区、转换和粘贴，并恢复原剪贴板；备份失败或焦点、选区发生变化时会取消操作。备用窗口的“复制结果”也会使用剪贴板。Windows 剪贴板历史和云同步另有规则，敏感场景建议关闭清简。

本地运行和安全扫描都不能保证绝对安全，也不能防御已经控制你账户或管理员权限的恶意软件。

## 9. 更新和卸载

### 9.1. 更新

1. 先在清简托盘菜单里选择“退出”。如果试用过扩展预览，先退出预览，勿同时运行多份助手。
2. 下载并解压同版 Windows 包，将其中 Qingjian-V2 内的新版文件复制到原 Qingjian-V2 文件夹，按提示替换同名文件。请保留原有的 models、user-data、local-config.json 和 startup-choice.json，不要删除整个原文件夹。
3. 在原文件夹里双击 Install.cmd（“更新清简.cmd”也可），之后仍从桌面“清简”启动。开机自启选择会保留。
4. 插件更新：将新版 Edge 文件放回原扩展目录；打开 edge://extensions，点击清简的“重新加载”，再刷新已打开的使用页面。若改了目录，应移除旧扩展，再加载新的 Edge 文件夹。
5. 旧的扩展错误记录不会自动清空，可在更新和刷新后清除记录，再观察是否出现新错误。无需反复重装浏览器。

### 9.2. 只删除 Edge 插件

1. 打开 `edge://extensions`，找到清简，点击“移除”并确认。
2. 移除后，可以删除独立插件的解压文件夹。

这不会自动卸载另外运行的桌面助手。

### 9.3. 完整卸载

1. 先在 Edge 移除清简扩展，释放浏览器连接。
2. 右键托盘清简，选择“退出”。
3. 回到原来的 `Qingjian-V2` 文件夹，双击 `Uninstall.cmd`。
4. 如果提示文件仍被占用，关闭清简或浏览器后重试，不要随意结束 Word、微信、Codex 等软件。

卸载会清理对应的程序、桌面快捷方式、自启和浏览器连接设置，并删除助手里的学习数据。它不会卸载微软输入法，也不会替你清除 Windows 剪贴板历史、浏览器历史或自行保存的备份。
